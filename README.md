# LUNA

LUNA — статическое веб-приложение на GitHub Pages. Клиентская часть находится в `index.html`, использует модульный Firebase Web SDK с CDN. Firebase-проект приложения — `luna-a9fa5`; конфигурация клиента не содержит серверных секретов. Серверная логика в проекте не используется.

## Текущее устройство

- Вход: Firebase Authentication, Email/Password.
- Данные: Cloud Firestore, база по умолчанию.
- Публикация сайта: GitHub Actions из `main` (см. `.github/workflows/pages.yml`).
- Цикл: дата начала хранится только в локальном `localStorage` браузера. Приложение не отправляет данные цикла в Firebase.
- Общая лента: отдельной функции публикации постов в интерфейсе сейчас нет. Правила заранее ограничивают будущую коллекцию `lunaPosts`; клиент публикации должен атомарно обновлять лимит постов.

## Коллекции Firestore

| Коллекция | Доступ |
| --- | --- |
| `lunaProfiles/{uid}` | Владелица; подруги только к профилям, содержащим разрешённый набор безопасных полей |
| `lunaPrivateProfiles/{uid}` | Только владелица; настроение и «любимое» |
| `lunaUsernames/{nickLower}` | Точный поиск по документу для вошедших участниц; доступны только ник и UID |
| `lunaFriendRequests/{fromUid~toUid}` | Читать могут только отправительница и получательница; отправить может владелица UID, принять/отклонить — получательница |
| `lunaFriends/{friendshipId}` | Только участницы этой связи; связь создаётся вместе с принятием заявки |
| `lunaChats/{chatId}/messages/{messageId}` | Только участницы подтверждённой дружбы |
| `lunaRooms/{roomId}` и `messages` | Комнаты читают участницы; сообщения каналов пишут создательница или администраторки |
| `lunaRoomInvites/{roomId~uid}` | Читать могут только отправительница и получательница; принять приглашение может получательница |
| `lunaFriendRequestLimits/{uid}` | Только владелица лимита; счётчик заявок за час |
| `lunaPostLimits/{uid}` | Только владелица лимита; счётчик постов за час |
| `lunaPosts/{postId}` | Только подтверждённая почта; максимум 10 публикаций за час |

Неописанные коллекции и действия запрещены правилами по умолчанию. Ограничения: не более 5 заявок и 10 постов за часовой интервал от первой операции. В том же Firestore transaction/batch записывается уникальный идентификатор события в личный ограниченный список; каждая заявка привязана к собственному токену и UID получательницы, каждый пост — к ID документа. Это не позволяет одной записи лимита покрыть пакет запросов к нескольким получательницам. Клиентские лимиты дополнены обязательными проверками правил.

Почта хранится в Firebase Authentication, а не в Firestore. Подтверждение почты проверяется правилами при отправке/повторной отправке заявки и создании поста. Вошедшая, но ещё не подтвердившая почту участница может просматривать приложение и обрабатывать уже полученные заявки.

## Совместимость и миграция профиля

Существующие документы и идентификаторы коллекций не удаляются и не переименовываются. Старые документы `lunaProfiles` могут содержать поля `mood` и `favorites`. Новая версия клиента при следующем входе читает старые значения от имени владелицы, переносит их в `lunaPrivateProfiles/{uid}`, а публичный документ сохраняет только ник, индекс ника, описание, интересы, фото и время обновления. Изображение и переписки остаются на прежних путях.

Пока старый профиль не мигрирован, правила не дают подругам читать его содержимое. Это предотвращает утечку старых приватных полей; владелица по-прежнему может его прочитать и обновить. Сами значения настроения и «любимого» сохраняются в приватном документе и в локальной копии профиля.

## Публикация правил

Из корня репозитория:

```sh
npm install --global firebase-tools
firebase login
firebase deploy --only firestore:rules
```

Файл `.firebaserc` выбирает `luna-a9fa5`, а `firebase.json` направляет Firebase CLI на `firestore.rules`. Перед публикацией проверь в Firebase Console, что выбран проект **Luna (luna-a9fa5)** и база **default**. Деплой правил не публикует сайт и не меняет документы.

## Известные ограничения

- В текущей сессии нет доступного Firebase CLI и инструментов управления Firebase Console. Поэтому опубликованное состояние проекта и успешность деплоя не подтверждены; файл правил нужно отправить командой выше из авторизованного окружения.
- Общая лента постов пока не реализована на клиенте. Правила уже требуют транзакционный счётчик для `lunaPosts`; будущую форму публикации надо строить с таким же атомарным обновлением `lunaPostLimits/{uid}`.
- Интерфейс назначения администраторок комнаты пока отсутствует. Правила позволяют создательнице безопасно обновлять список администраторок, а публиковать в канале могут только участницы из этого списка или сама создательница.
