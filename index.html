Правила сообщества LUNA 🌙

Черновик для ознакомления. LUNA — пространство поддержки и уважительного общения девушек.

  1. Будь вежлива: запрещены травля, угрозы, унижение и публикация чужих личных данных.
  2. Не публикуй спам, мошеннические ссылки, незаконный или опасный контент.
  3. Публикуй только материалы, на которые у тебя есть права. Анонимность не отменяет ответственности.
  4. Используй жалобы и блокировку для защиты. Злоупотреблять ими нельзя.
  5. Возраст участия — от 14 лет. Не указывай адрес, школу, документы, пароли и коды.
  6. Администрация может скрывать нарушающий правила контент и ограничивать доступ.

Это рабочий черновик, он требует проверки владельцем сервиса и юристом до публикации.

Политика конфиденциальности LUNA 🔒

Черновик для ознакомления. LUNA использует Firebase Authentication для входа и Cloud Firestore для профиля, публикаций, заявок и сообщений.

  • В открытый профиль включаются ник, фото, описание и интересы. Приватный профиль доступен только владелице и подругам.
  • Личные данные и сообщения обрабатываются для работы функций приложения. Жалобы могут храниться для рассмотрения модерацией.
  • Данные цикла должны храниться только локально. Не добавляй их в профиль или публикации.
  • Можно выгрузить JSON и запросить удаление аккаунта в профиле. Из-за вложенных коллекций часть серверных данных требует администраторской очистки.
  • Firebase и GitHub Pages могут обрабатывать технические данные согласно своим политикам.

Владелица проекта: укажи контакт для запросов о данных до публичного запуска. Черновик требует юридической проверки.
